Default behavior

This page lists all the variables that may be customized to control the behavior of integrate!.

This variables are intentionally unexported, meaning that they must be accessed as Vlasova.variable_name, and they can only be changed from the inside of the module defined by Vlasova. To accomplish the latter, the macro @vlasova has been implemented.

Vlasova.FFTW_flags — Constant
FFTW_flags = FFTW.ESTIMATE

Flags used by FFTW on the Fourier Transform plans inside Vlasova.

Notes

  • This value must be changed from inside Vlasova. If you want to change it, use @vlasova.
source
Vlasova.checkpoint_percent — Constant
checkpoint_percent = 100

Specify some percentage of the simulation to repeatedly back up the data.

Notes

  • When checkpoint_percent == 100 (default), the simulation will not be backed up.
  • This value must be changed from inside Vlasova. If you want to change it, use @vlasova.
source
Vlasova.continue_from_backup — Constant
continue_from_backup = false

Specify if Vlasova should look for an unfinished simulation in the path given by data_path, and complete it.

Notes

  • This value must be changed from inside Vlasova. If you want to change it, use @vlasova.
source
Vlasova.data_path — Constant
data_path = ""

Path to save the results of the simulation.

Notes

  • When set to "" (empty String, default value), the results of the simulation will not be saved.
  • This value must be changed from inside Vlasova. If you want to change it, use @vlasova.
source
Vlasova.integrator — Constant
integrator = verlet_velocity

Default symplectic integrator to be used by Vlasova.

Notes

  • This value must be changed from inside Vlasova. If you want to change it, use @vlasova.
source
Vlasova.save_distribution_times — Constant
save_distribution_times = Float64[]

Define instants to save the distribution function(s).

Notes

  • This value must be changed from inside Vlasova. If you want to change it, use @vlasova.
source
Vlasova.velocity_filtering — Constant
velocity_filtering = true

Define if Vlasova should use anisotropic filtering in the transformed-velocity space.

Notes

  • This value must be changed from inside Vlasova. If you want to change it, use @vlasova.
source
Vlasova.external_potential — Function
external_potential(box, time) = 0.0

Define some external potential acting on the system. It must be a function of box::Vlasova.Box and time::Float64

Notes

  • This value must be changed from inside Vlasova. If you want to change it, use @vlasova.
